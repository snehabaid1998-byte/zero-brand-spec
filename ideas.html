The system

Brand context: so nobody re-briefs the brand again.

You built Agent context so nobody has to keep explaining the ICP to an agent. I'd build the same thing for the brand. It's one small folder of tokens, voice rules and motifs that lives inside every tool people already use. A designer prompting Claude Code, a founder making a LinkedIn post, an engineer building a widget: they all start on brand without importing a style guide or pasting hex codes.

"Local" is the point. It sits next to the work, in the repo, the Figma file and the prompt, instead of in a PDF somewhere. It's also local to each market. One switch changes spelling, dates and the trust line for the US, the EU, Finland or Germany.

    Screen to space

    A brand that only works on screens isn't finished.

    The posting mentions billboards, stunts and events. A screen forgives a lot. A wall doesn't: people walk past at speed, the light changes, and colour turns into paint, steel and felt. I trained as an architect and have built interiors, so this is the part of the job I'm most at home in. Two quick tools show how I think about it.

    How big does it need to be?

    Drag the distance. The headline height and halftone spacing are worked out so the wall reads properly from there.

    67 mmmin. headline height
    12 mmdot spacing so dots still read as dots
    5.8 stime to read it, walking past

    Rules of thumb: about 25 mm of letter height for every 3 m of distance, dots about 5 arcminutes apart, walking speed 1.4 m/s. On site I'd test with a printed swatch.
